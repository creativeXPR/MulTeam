Build a MulTeam plugin

About 10 minutes · from a template to the gallery

1 · What a plugin is

A MulTeam plugin is a small JavaScript program that adds features to the editor: palette commands, a status item in the footer, autocomplete suggestions, tools that rewrite code or create files, and reactions to opening or saving files.

Plugins run in a sandbox (a Web Worker). They can't touch the app, your disk or the network directly. Everything goes through the multeam API, and anything sensitive needs a permission that you see before installing.

Themes, icon themes, snippets and language support come from VS Code extensions (Extensions view). Plugins are for everything else, especially features unique to MulTeam.

2 · Create one from a template

  1. Open Plugins in the sidebar (the plug icon), then the Templates tab.
  2. Pick a template, such as Hello command, and press Use template.
  3. Give it a name. It's created and starts running straight away; you'll find it under Installed.
  4. Press Ctrl+K and type “Say hello” to try it.

3 · The files

Press Open folder on the plugin's card. Inside:

multeam-plugin.json   the manifest
main.js               your code
README.md             notes for users

The manifest describes the plugin:

{
  "id": "word-tools",            // lowercase, digits, dashes — unique in the gallery
  "name": "Word Tools",
  "version": "0.1.0",            // raise it for every published update
  "description": "Handy text commands",
  "main": "main.js",
  "permissions": ["editor"]
}

4 · The API

Everything is on the global multeam object. Calls that talk to the app return promises, so await them.

// commands — shown in Ctrl+K as "Plugin name: title"
multeam.commands.register('upper', 'UPPERCASE selection', async () => {
  const text = await multeam.editor.getSelectedText();
  if (!text) return multeam.window.showError('Select some text first.');
  await multeam.editor.replaceSelection(text.toUpperCase());
});

// window
multeam.window.showMessage('Done!');
const name = await multeam.window.showInput({ title: 'Rename', label: 'New name' }); // string | null
multeam.window.setStatus('3 TODOs');          // footer text; '' hides it

// editor (needs "editor")
await multeam.editor.getText();               // null when no file is open
await multeam.editor.insertText('// hi');
await multeam.editor.getFile();               // { path, language }

// workspace (needs "workspace.read" / "workspace.write")
await multeam.workspace.listFiles();          // paths relative to the project
await multeam.workspace.readFile('package.json');
await multeam.workspace.writeFile('notes.md', '# Notes');

// completions — type the label in a file of that language
multeam.languages.registerCompletions('python', () => [
  { label: 'main', insertText: 'if __name__ == "__main__":\n\t${1:main()}', detail: 'main guard' }
]);

// events
multeam.on('open', ({ path, language }) => {});
multeam.on('save', ({ path }) => {});

5 · Permissions

PermissionUnlocks
editorReading and changing the open file
workspace.readListing and reading project files
workspace.writeCreating and changing project files

Commands, messages, input prompts, the status item, completions and events need no permission. Ask only for what you use: people see the list before installing, and an update that adds permissions asks them again.

6 · Test & debug

  • Edit main.js in any editor (MulTeam included) and press Reload on the card. Changes apply immediately.
  • If the plugin crashes, the card shows the error with the line number in your main.js.
  • Calling an API without its permission gives a clear error naming the permission to add.
  • Use the switch on the card to disable a plugin without uninstalling it.

7 · Package & share

Export on the card saves a single .mtplugin file (a zip of the plugin folder, up to 700 KB). Send it to anyone, and they install it with Installed → .mtplugin…

8 · Publish to the gallery

  1. Sign in (your avatar, top right).
  2. Press Publish… on the plugin's card, check the summary, and add an optional changelog.
  3. It appears in Plugins → Gallery for every MulTeam user, under your display name (never your email).

The first person to publish an id owns it, so only you can publish new versions of your plugin. Published versions can't be changed.

9 · Ship updates

Raise version in the manifest (for example 0.1.0 → 0.2.0), test with Reload, then Publish… again. Users see Update to 0.2.0 in the Gallery. Changed your mind? Unpublish removes it from the gallery, and people who installed it keep their copy.

Help

MulTeam is a local-first code editor with optional real-time collaboration.

How to

  • New project — pick a name and a folder. Nothing touches the cloud unless you turn on cloud sync.
  • Cloud sync — turn it on (per-project) to collaborate live with others; you'll be asked to sign in the first time.
  • Ctrl+K — jump to any project, open file, or app command.
  • Ctrl+P — open any file in the project by typing part of its name (type > for commands).
  • Ctrl+Shift+F — search text across every file in the project; click a result to jump to it.
  • Language support — Extensions view → Language support → Install (JavaScript/TypeScript, Python, C/C++, PHP, Java, C#). Downloads the language server once (Java uses your Java 21+ if you have it; C# needs the .NET SDK); then IntelliSense, go to definition (F12) and real errors work. The footer shows its status.
  • Formatting — Shift+Alt+F (Edit → Format Document). Install Prettier / Ruff under Extensions → Formatters & linters; C/C++, Java, PHP and C# use their language server. Turn on Format on save in Settings.
  • Ctrl+Shift+X — Extensions: install color themes, file icon themes and snippets from Open VSX. Switch with View → Color Theme… / File Icon Theme….
  • Plugins — the plug icon in the sidebar: install from the Gallery, start from a Template, or read the tutorial (Help → Plugin Tutorial).
  • Ctrl+Shift+G — Source Control: stage, commit, pull and push. Click the branch name in the footer to switch or create branches.
  • Ctrl+J — show or hide the bottom panel. Click the ⊗ / ⚠ counts in the footer to jump to Problems.
  • Ctrl+` — open the terminal in the current project's folder. Use + for more, and pick PowerShell, Command Prompt or Git Bash.
  • Ctrl + / Ctrl − — zoom the whole app in or out; Ctrl+0 resets. Remembered between launches.
  • Right-click a file — rename, duplicate, save as, or delete it.
  • Switching projects — only one project stays open at a time; you'll be asked to confirm before switching away from one.
